How the value is computed

Implied value = TVL × (0.02 + 0.30 × score1.5), where score = 0.45 × log TVL + 0.25 × 7-day growth + 0.20 × years tracked with no token recorded + 0.10 × chain breadth. Every input comes from the snapshot itself — no name is ever hardcoded, so the same formula ranks a protocol that does not exist yet. A protocol is a candidate only when its record carries no token (gecko_id and symbol both null) and it is not a wrapped, staked or bridged product of a token that already trades. The snapshot's record is not proof: a protocol listed here records no token, it is not claimed to have none. Farm plans are generated from the protocol's category, main chain and TVL band, and state what each step costs and how long it takes.
