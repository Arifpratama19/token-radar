A token launch radar: a Node.js program that reads a sealed DefiLlama snapshot of 758 protocols, finds the ones that record no token yet, ranks them by what a launch would be worth, and writes a web dashboard with a farm plan for each one.

Built for the make.fun bounty [Build the best token launch radar](https://make.fun/bounty/token-radar-01).

## What it does

- **Finds the launches still to come.** A protocol is a candidate only when its DefiLlama record carries no token (`gecko_id` and `symbol` both null) and it is not a wrapped, staked or bridged product of a token that already trades. That gives 198 candidates, including the full 40-protocol watchlist plus 158 more found below the $50M floor.
- **Ranks by an implied value from the snapshot's own figures.** `implied = TVL × (0.02 + 0.30 × score^1.5)`, where `score = 0.45·log TVL + 0.25·7-day growth + 0.20·years tracked with no token + 0.10·chain breadth`. No name is hardcoded, so the same formula ranks a protocol that does not exist yet.
- **Shows how to farm each one.** Every board row carries a 5-step plan generated from the protocol's category, main chain and TVL band, with what each step costs and how long it takes. The dashboard generates the same steps from the same code (`dashboard/farm.js`), so the page and the board can never disagree.
- **Separates the already-launched.** Protocols whose token already trades are shown in their own strip, never mixed into the ranking.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```

Reads the snapshot, writes `out/board.json`, `out/dashboard/` (the page plus its data), `out/screenshots/` and `out/dossier.json`. The run is deterministic: the same snapshot in, the same bytes out.

Open `out/dashboard/index.html` in a browser. Click any row for its detail view with the score breakdown and farm plan; use the search, category, chain and TVL filters, or deep-link with `?detail=<slug>`, `?category=<name>`, `?chain=<name>`, `?watchlist=1`.

## Layout

- `main.ts` — the program: snapshot in, ranked board + dashboard data + dossier out
- `dashboard/` — the static page (`index.html`, `app.css`, `app.js`, `farm.js`); `data.js` is generated by `main.ts`
- `vendor/makefun-board.ts` — the kit's dossier library, byte for byte
- `screenshots/` — the three dossier screenshots of the rendered dashboard

Data: DefiLlama protocols snapshot frozen 2026-11-14. Implied values are this entry's own claim, not a prediction that a token will launch.
